一、内容怎么放

1. 多项内容用列表

定义
列表用来排列一组同类项。
无序列表
ul。项前为圆点。不表示先后。
有序列表
ol。项前为序号。表示先后。
列表项
li。必须写在 ul 或 ol 内部。
ul
  • Serif 衬线
  • Sans-serif 无衬线
  • Script 手写
ol
  1. Coffee
  2. Milk

嵌套

写法
子列表写在父级 li 内部，本身仍是完整的 ul 或 ol。
注意
课件示例把 li 写进了另一个 li。该写法不正确。

2. 一块内容用容器

定义
div 和 span 没有固定含义，只用来分组。
div
块级元素。独占一行。用来包一块内容，例如一栏新闻。
span
行内元素。不换行。用来标出几个字，再单独设置样式。

3. 给元素命名

定义
id 和 class 都是名字，供 CSS 选中元素。
id
同一页只能出现一次。选择器写作 #id。
class
可以重复使用。一个元素可以有多个 class，用空格分开。选择器写作 .class。

二、外观怎么定

4. 一条规则的写法

定义
CSS 规则由选择器和声明组成。声明写在花括号内。
声明
格式为 属性: 值;。每条声明以分号结束。
注释
/* 注释 */ 不被浏览器执行。
可读性
一条声明占一行。

h1 { color: blue; font-size: 24px; }

选择器是 h1。color、font-size 是属性。blue、24px 是值。

课件正文示例为 24px。同页示意图有一处写成 12px。此处用 24px。

5. 样式写在三处

内联样式
写在元素的 style 属性中。只作用于该元素。表现和内容写在一起，适合只用一次。例：<p style="color: red;">文字</p>
内部样式表
写在 head 的 style 元素中。只作用于本页。例：在本页 <head> 里写 <style>p { color: red; }</style>
外部样式表
写在独立的 css 文件中，用 link 引入。可供多页共用。改一个文件，各页一起变。例：独立文件 mystyle.css，页面写 <link rel="stylesheet" href="mystyle.css">

外部样式表的引入写法：

<link rel="stylesheet" type="text/css" href="mystyle.css">

6. 同一属性以哪条为准

规则
同一属性被多处规定时，优先级高的声明覆盖优先级低的声明。
顺序
内联样式 > 内部样式表 > 外部样式表 > 浏览器默认样式。
同级
来源相同、选择器相同时，后出现的声明覆盖先出现的声明。
  1. 内联样式<p style="color: red;">…</p>
  2. 内部样式表<style>p { color: green; }</style>
  3. 外部样式表<link rel="stylesheet" href="mystyle.css">
  4. 浏览器默认样式不写任何 style / link 时的默认外观

上表按优先级从高到低排列。id 选择器比 class 选择器、元素选择器更具体。本周不展开计算。

重点：删去内联样式后，内部样式表生效

7. 三种选择器

元素选择器
写元素名。选中全部该元素。例：p { color: black; }
id 选择器
# 加 id。只选中这一个。例：#para1 { text-align: center; }
class 选择器
. 加 class 名。选中全部该 class。点号写在 CSS 中，不写在 HTML 中。
重点：# 只选一个，. 选一组

8. 本周三个属性

颜色
color 可用多种写法表示同一种红：
  • 颜色名：red
  • 十六进制：#ff0000
  • rgb 数值：rgb(255, 0, 0)
  • rgb 百分比：rgb(100%, 0%, 0%)
对齐
text-align 取值 left、center、right、justify。justify 使每行左右两端对齐。
字体
font-family 从左到右依次尝试。font-size 设置字号。课件示例：h1 为 40px，h2 为 30px，p 为 14px。
背景图
background-image 设置背景图像。默认平铺，铺满该元素。
red
#ff0000
rgb(255,0,0)
重点：color、text-align、font-family、font-size
